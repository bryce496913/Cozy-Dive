# Low-poly Pass 015 baseline and inventory status

Base: `e460f29`, merged stabilization Pass 108. No runtime or asset files change in this pass. The authoritative art direction is complete; the semantic inventory is **not yet certified complete**.

`asset-inventory.json` is a reproducible census generated by `node tools/audit/low-poly-inventory.mjs`. It includes every mesh-bearing node in shipped GLBs (including LODs/collision helpers), and direct geometry/render-object construction sites in TypeScript. Each record has source, identity, geometry/material evidence, dependency review fields, provisional pass ownership and replacement status. It intentionally retains helpers instead of silently excluding possible visible assets. It does not count each instanced copy as a separate owned asset.

Unresolved: source scanning cannot certify indirect factory-created objects or resolve every shared node to all habitats. Material/animation/dependency review fields for source sites need manual call-graph review. Mixed-library pass assignments are provisional. Do not treat this census as satisfying the requirement that every semantic asset has verified ownership and dependencies. Complete that review before replacement work begins.

Playable coverage: office and aquarium exterior, home aquarium, outer reef with open-water visitor corridor, kelp forest, shipwreck deck/hold/bridge, sea cave and Antarctic under-ice habitat. Passage/shaft geometry is included as shared infrastructure. The outer open-water corridor is not a separately registered album habitat. The collection contains 115 primary slots and 22 authored rare identities; these are not total visible-asset counts.

Art sources: `tools/art/pass*` contains Blender generation scripts/source files; `src/assets/AssetRegistry.ts` and `public/assets/manifest.json` describe shipped libraries. Direct builders under `src/environment`, creature systems and rendering utilities supply procedural art, terrain, props, particles and fallback geometry. Shared art flows through `TankCollectionArt`, fish rigs, registry descriptions and six rare-library owners. Animation spans morph targets, skeletal rigs, procedural controller transforms and plant shaders. Material utilities include PBR/triplanar, gelatinous transparency and current-driven vegetation shaders; these need planned redesign under the new palette/faceted rules.

## Reproduction and remaining baseline work

Use `npm run build`, `npm run typecheck`, `npm run lint`. Focused data/save/resource regression: `npm run test -- tests/collection-acceptance.test.ts tests/shared-models-scale.test.ts tests/asset-lifecycle.test.ts tests/save-compatibility.test.ts --maxWorkers=1`.

For repeatable local rendering use `npm run dev -- --port 5178`, then the existing `validation/v08/collection-integration.mjs` with `COZY_ACCEPTANCE=1`, `COZY_CLEANUP=1`, `COZY_URL`, `COZY_CHROMIUM`, `COZY_PLAYWRIGHT` and a fresh `COZY_OUTPUT`. For habitat baselines use existing habitat-specific validation harnesses listed under `validation/`; record camera, detail setting, DPR, renderer, warm/cold state and population alongside screenshots and `renderer.info.render`. Never call SwiftShader a real GPU. Full world detail caps DPR at 1.75, lighter at 1; previews stay DPR 1 with 200×140/520×360 canvases. Measure actual Air frame timing with Settings → Show frame time; record browser, chip/RAM, display and power mode.

Remaining work: fresh representative screenshots and timing for every habitat, complete semantic asset/caller mapping, reference-image confirmation and actual-device profiling. This is a draft planning deliverable, not acceptance or authorization to rebuild the library.
